# CompleteDiscordQuest for Vencord

A Vencord(VC) plugin that completes you multiple discord quests in background simultaneously.

## NOTICE
This project is for educational purposes and proof-of-concept only. Using this plugin violates Discord's Terms of Service. I am not responsible for any banned accounts or legal issues resulting from the use of this code.
## Features:

- Auto enroll quests
- Set which type of quest can be farmed
- Set which type of reward can be farmed

## 🚀 Quick Installation (Windows)

1.  Ensure you have [Vencord](https://vencord.dev/) installed.
2.  Run .\injectquest.bat
